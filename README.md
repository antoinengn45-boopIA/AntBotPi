# AntBotPi
Bienvenue sur le projet **AntBotPi** !

Cette IA simple est conçue pour démontrer les bases de l'apprentissage automatique dans une interface Web interactive.

## Structure
- `index.html` : L'interface utilisateur de l'IA.
- `style.css` : Le design et la mise en page.
- `script.js` : La logique de l'IA (apprentissage simple côté client).

## Utilisation
1. Clonez ce dépôt.
2. Ouvrez `index.html` dans votre navigateur.
3. Entrez des données et laissez AntBotPi apprendre !
